# 玩家手冊 — Taipei 101 午夜疾走 Midnight Circuit

> 🎮 立即遊玩:**<https://swchen44.github.io/racing-101-game/>**
> 桌機、平板、手機(請橫屏)皆可;支援離線遊玩。

---

## 1. 開始遊戲

1. 開啟遊戲網址,輸入你的 **Email 帳號**(不分大小寫,只作為排行榜識別,不會寄信)
2. 選擇語言(中文/EN)
3. 按「開始遊戲」進入賽事設定,依序選擇:
   - **遊戲模式**(單人計時/警車追逐/大獎賽)
   - **對手強度**(低/中/高 — 影響 AI 車手實力)
   - **時段**(夜晚/黃昏/白天 — 純視覺,不影響物理)
   - **賽道**(4 條,卡片上有風景照、介紹與難度星等)
   - **車型**(8 台,360° 旋轉展示與性能條)
   - **變速箱**(自排/手排)
4. 按「出發」,倒數 3-2-1-GO!

## 2. 安裝成 App(可離線玩)

| 裝置 | 步驟 |
|---|---|
| iPhone / iPad(Safari) | 開網址 → 分享 ⬆️ → **加入主畫面** |
| Android(Chrome) | 開網址 → 右上 ⋮ → **安裝應用程式** |
| 電腦(Chrome/Edge) | 網址列右側 ⊕ 安裝圖示 |

> 安裝後**先在有網路時完整玩一場**,遊戲資源就會存進裝置,之後斷網也能玩。
> 離線時全球排行榜暫停,成績仍會存在本機,回到線上後新成績照常上傳。

## 3. 操作

### 鍵盤(桌機)

| 按鍵 | 動作 |
|---|---|
| `W A S D` 或 方向鍵 | 油門/煞車(倒車)/左右轉向 |
| `Space` | 手煞車 — 過彎時按住即甩尾 |
| `⇧ Shift` | **BOOST 加速**(每場 3 次) |
| `Q` / `E` | 降檔/升檔(手排模式) |
| `C` | 切換視角:追逐 → 遠景 → **駕駛艙** → 車頭 |
| `M` | 開/關**後視鏡**(畫面上方即時後方畫面) |
| `R` | 重新開始本場 |
| `Esc` | 放棄比賽(會再確認一次;放棄不記成績) |

### 觸控(手機/平板,橫屏)

- 左下:◀ ▶ 轉向;左上方:⚡ **BOOST**
- 右下:油門(綠)/煞車(紅)/甩尾(琥珀)
- 頂部:📷 視角、🖥 後視鏡;左上「✕ 放棄」
- 手排模式會多出 + / − 換檔鈕

## 4. 賽事規則

- 每場 **2 圈**,賽道上有 8 個隱形檢查點依序驗證 — 抄捷徑無效
- 撞護欄會噴火花並損失速度;逆向行駛出現「逆走」警告
- **BOOST**:每場 3 顆(HUD 左下藍點),按一次全力衝刺 5 秒,極速上限翻倍 — 留給直線!
- **最速單圈**依「賽道×模式」分開記錄在你的裝置,破紀錄有特效
- 完賽成績自動上傳全球排行榜(依 模式×賽道×難度 分榜,顯示 Email、遮罩 IP 與你當地時間)

### 三種模式

| 模式 | 玩法 | 勝利條件 |
|---|---|---|
| ⏱ 單人計時 | 只有你和碼表 | 跑完 2 圈,追求最短總時間 |
| 🚨 警車追逐 | 一台警車在前方**堵路**(會等你、可被超越),一台在後方**追撞**(會 PIT 撞你車尾);甩開太遠會遭遇路障攔截(可撞飛) | 完成 2 圈。被警車貼身逼停(低速被貼 <7m 數秒)→ BUSTED 出局 |
| 🏆 大獎賽 | 與 5 台 AI 車手同場,它們會搶線、互相閃避、也會犯錯 | 2 圈結束時名次越前越好,搶 P1! |

## 7. 常見問題

- **畫面很卡?** 遊戲會自動降畫質保流暢;關閉其他分頁/App 有幫助
- **沒有聲音?** 瀏覽器要求使用者互動後才能出聲 — 按過「開始遊戲」就有了
- **手機直屏進不去?** 設計上僅支援橫屏,轉過來就好
- **成績沒上排行榜?** 放棄或 BUSTED 的場次不記;離線場次只存本機
- **賽道旁的「歡迎刊登廣告」是什麼?** 真的可以刊登 — 洽遊戲管理者
