# Taipei 101 Midnight Circuit — UI/UX 審查報告

審查人:資深遊戲 UI/UX 專家(賽車遊戲介面背景)
日期:2026-08-21
基準解析度:1280×720 桌機;抽驗 1180×820(平板 touch)與 844×390(手機 touch)

## 一、評分準則 (Rubric)

總分 = Σ(單項分數 × 權重),每項 0–10 分。

| # | 準則 | 權重 | 說明 / 檢核點 |
|---|------|------|----------------|
| R1 | 視覺層級與資訊優先序 | 15% | 主要 CTA 是否最醒目;比賽中速度/圈次/名次等關鍵資訊是否第一眼可得;次要資訊(IP、來源)是否退居次位 |
| R2 | 對齊 / 間距 / 一致性 | 12% | 卡片欄距、標題節奏、按鈕尺寸一致;同類元件同視覺語言(clip-path 斜角、霓虹色系) |
| R3 | 可讀性(字級 / 對比,WCAG AA 參考) | 13% | 內文 ≥ 4.5:1、大字 ≥ 3:1 對比;最小字級 ≥ 10px 且非關鍵;HUD 疊在 3D 場景上仍可讀 |
| R4 | 互動回饋(hover / press / 選取態) | 12% | 按鈕 hover 有變化、卡片選取態明確、tab 選取態明確、觸控按鈕有 press 態;可點擊元素游標為 pointer |
| R5 | 觸控目標尺寸(≥44px) | 8% | touch 佈局下所有可點擊目標 ≥ 44×44px(含 HUD 小按鈕、tab) |
| R6 | 雙語完整性(中 / EN) | 10% | 切 EN 後無漏翻、無破版;動態內容(卡片、排行榜、結算)也跟著切換 |
| R7 | 響應式 | 10% | 1280×720 為主;1180×820 平板與 844×390 手機無重疊、無溢出、無被裁切的關鍵資訊 |
| R8 | 流程清晰度 | 10% | 使用者永遠知道下一步(主 CTA、返回、Enter 快捷);比賽中知道目標(下一檢查點、剩餘圈數) |
| R9 | 錯誤 / 空狀態處理 | 5% | Email 錯誤有明確提示與恢復;排行榜空狀態有引導文案;上傳失敗有降級說明 |
| R10 | 美術風格一致性 | 5% | 午夜霓虹 / 賽博台北語言貫穿:翡翠+琥珀+青色霓虹、斜角切邊、玻璃擬態;無出戲元素 |

### 逐畫面觀察(修改前)

1. 標題/Email 錯誤:標題視覺出色;但 Email 錯誤提示採 `wwBlink` 動畫,截圖常落在「不可見」半週期,錯誤幾乎看不到;輸入框僅 220px,長 Email 被截斷。
2. RACE SETUP:分頁清楚,但主 CTA「出發」需捲到頁底才看得到,長頁中途看不到下一步;EN 版卡片主標與副標重複(TIME ATTACK / TIME ATTACK)。
3. 排行榜:三排 tab(模式/賽道/難度)無群組標籤,使用者不知每排意義;空狀態文字暗(#56789a)且過於簡短。
4. HUD solo:**嚴重** — 放棄/後視鏡兩顆按鈕(top 96/138px)壓在 race-pod 的 LAST/BEST 兩列上,關鍵圈速資訊被遮;race-pod 玻璃過透,疊在亮窗大樓上可讀性弱。
5. GP/警車 HUD:名次 P1/6 與通緝條本身清楚,連帶受 4 的按鈕遮擋問題。
6. 駕駛艙+後視鏡:大致良好。
7. 放棄確認框:清楚。
8. 結算 FINISH:後視鏡子母畫面殘留在畫面頂端,壓住 FINISH 大標。
9. 平板/手機:手機時速表壓住左上圈速板;平板/手機的視角、後視鏡切換鈕壓在後視鏡子母畫面上;Boost 剩餘點被轉向鈕蓋住;tab 與 HUD 小按鈕觸控目標偏小。

## 四、最終總分

**修改前 6.3 / 10 → 修改後 8.1 / 10(達標,Round 1 即達 ≥8)**

一輪修改集中處理「資訊遮擋(D1/D3/D9)」「流程斷點(D4/D6)」「雙語破版(D2/D12)」三類最高影響缺陷,
分數提升皆對應可見的畫面改善。R10 美術本已優秀,維持不變。

### 尚存的次要待辦(未達阻擋標準,留待後續)
- 結算畫面開啟時,背景 HUD(race-pod/speed-pod/minimap)仍可見,略顯雜訊;可在 results 開啟時一併隱藏(需擴充畫面切換邏輯,超出本輪最小改動原則)。
- sticky 行動列在捲到最頂時,漸層底會輕觸 TRACK 區塊卡片頂緣(標準黏底頁尾行為,捲動後即分離)。
