> 遊戲網址:<https://swchen44.github.io/racing-101-game/>(網頁+手機 App,免下載)

## 1. 為什麼在賽車遊戲裡刊廣告?

- 看板設置於賽道**直線段、面向來車**,玩家視線自然停留(同 F1 賽場廣告邏輯)
- 每場比賽 2 圈,**每位玩家每場保證看到每面看板 2 次**
- 全遊戲**只有 8 面看板**(每賽道 2 面)——稀缺、不干擾、不會被玩家反感或忽略
- 夜間為發光燈箱、白天為印刷看板,融入場景質感,不是突兀的彈窗

## 3. 素材規格

| 項目 | 規格 |
|---|---|
| 尺寸 | **1024 × 512 px**(2:1),PNG 或 JPG,≤ 500KB |
| 安全區 | 四邊各留 5% 內縮,重要文字置中 |
| 風格建議 | 深色底+高對比主題色在夜間燈箱上最亮眼;避免細小文字(車速下閱讀時間短) |
| 禁止 | 動圖/影片(現階段)、違法或不當內容 |

## 4. 成效數據

每位玩家每圈經過看板即記錄一次曝光,存於資料庫(含時間戳)。可提供:
- 各看板**總曝光數**與**每日曝光趨勢**
- 範例報表:「`xinyi:0` 過去 30 天共 N 次曝光,日均 M 次」

計價建議採**包檔期固定價**(例:單面看板包月),數據作為續約參考,不採 CPM 計價。

## 5. 檔期與上下架

- 上架:提供素材後**當日生效**(玩家下次開啟遊戲即見)
- 支援預約檔期(起訖日),到期自動下架
- 未售出的看板顯示「歡迎刊登廣告 YOUR AD HERE」

## 附錄:營運者上架 SOP(內部用)

1. 素材檢查:1024×512、大小 ≤500KB、內容合規
2. 上傳圖片:Supabase 後台 → Storage → `ads` bucket(public)→ Upload → 複製公開網址
   (格式:`https://<專案>.supabase.co/storage/v1/object/public/ads/<檔名>`)
3. 建檔期:Table Editor → `sponsors` → Insert:
   `slot`(如 `xinyi:0`)、`name`、`image_url`、`active=true`、`starts_at`/`ends_at`(可空)
4. 驗收:開遊戲跑該賽道確認顯示
5. 下架:`active=false` 或等檔期到期
6. 報表:SQL Editor 執行(見管理者手冊 §4.3)

> 整條鏈路已於 2026-08 端到端實測通過(Storage 圖 → sponsors 表 → 遊戲看板顯示 → 曝光入帳)。
